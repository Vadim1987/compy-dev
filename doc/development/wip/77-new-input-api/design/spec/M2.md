## Scope

Move widget construction from inside `ConsoleController` to framework startup: the widget is
created **once**, never destroyed, and reused. Expose `compy.input.show`/`hide` on the
namespace. **Zero behaviour change** for existing examples (legacy globals untouched until M8).

## Contract (this milestone)

- **Singleton lifecycle.** `UserInputController` is instantiated **once at startup (lazily)**;
  no per-call construction. Per-session allocation (NFR-1) is gone.
- **`compy.input.show(config)`** — activates the singleton; sets `love.state.user_input` to the
  instance. This milestone wires the `show`/`hide` surface; the full `config` field set
  (`highlighter`/`validator`/`cursor`/etc.) is exercised, but `configure`/`clear`/cursor/text
  live-edit land in **M7**.
  - **`show()` while already active → no-op by default** (D-2): the call does nothing, the
    active session is untouched, no error, no cancel chain.
  - **`show({force = true})`** reconfigures in-place (content replaced if `text` given, else
    preserved), still no cancel chain.
- **`compy.input.hide()`** — deactivates without firing the cancel chain; content preserved;
  `love.state.user_input` set to `nil`.
- **`compy.input` table** is created once at namespace setup; `show`/`hide` mounted on it.
- **`oneshot` is NOT removed here** — it continues to drive submit through M2–M5 (removed in M6).

## Files

- `src/main.lua` — create the singleton instance at startup.
- `src/consoleController.lua` — remove per-call construction; wire to the singleton.
- `src/userInputController.lua` — add `show()`/`hide()` state-change methods.
- `src/compy_namespace.lua` (or equivalent) — create the `compy.input` table; mount
  `compy.input.show` / `compy.input.hide`.

## Acceptance

- Singleton created once at startup; not re-created per input call; no per-session allocation.
- `show()` on an active singleton is a no-op; `show({force=true})` reconfigures in place;
  neither fires a cancel chain.
- `love.state.user_input` points to the instance on `show()`, `nil` on `hide()`.
- Existing examples still work (legacy globals untouched); all existing tests pass.
