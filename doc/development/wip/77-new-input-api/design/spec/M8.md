## Scope

Remove the legacy text-input globals and migrate the in-repo examples that used them to the
`compy.input.*` callback API.

| | |
|---|---|
| **Depends on** | **M6 and M7** — migration needs the full surface: `show()` config (M2+M7), submit/cancel callbacks (M6), `set_text`/cursor (M7). |
| **Unblocks** | — (terminal milestone) |
| **Realises** | D-1 (legacy removal), D-10 (everything-under-`compy.input.*`) |
| **Risk** | Examples are the only consumers (contained blast radius). A window exists (M3-slot onward) where text-input examples don't run on the dev build — internal, acceptable (unreleased; old releases remain). |

## Contract (this milestone)

- **Removed globals** (no facades, no `strict_input` flag): `user_input()`, `input_text()`,
  `input_code()`, `validated_input()`, `write_to_input()`. The reftable / `is_empty()` polling
  idiom goes with them. Replacements (per `../spec.md` §5):
  - `user_input()` → observe via `compy.input.after_submit(result)`.
  - `input_text(p,i)` → `compy.input.show({prompt=p, text=i, validator=InputEvalText})` + `after_submit`.
  - `input_code(p,i)` → `compy.input.show({prompt=p, text=i, highlighter=lua_hl, validator=InputEvalLua})` + `after_submit`.
  - `validated_input(fn,p)` → `compy.input.show({prompt=p, validator=ValidatedTextEval(fn)})` + `after_submit`.
  - `write_to_input(c)` → `compy.input.set_text(c)`.
- **`love.state.user_input`** driven solely by `compy.input.show()`/`hide()`; no separate legacy
  code path.
- **Migration scope:**
  - **Priority (release-blocking):** `tixy` (`input_code` + `write_to_input` + `user_input`) and
    `balloons` (`input_text` + `user_input`). `maze` named by stakeholders but not in repo →
    on arrival.
  - **Convert-or-exclude (owner's release call):** `repl`, `guess`, `valid` (trivial REPL
    conversions), `turtle` (its `input_text` migrates; its native `love.keypressed` movement keeps
    working under D-9). Any not converted in time are excluded from the next release, not blocking.
  - **Unaffected:** native-only examples (`pong`, `life`, `paint`, `sapper`, `sine`, `clock`,
    `drawdebug`) — D-9 coexistence; "only text fields" break.

## Files

- `src/consoleController.lua` — remove the five legacy entry points.
- `src/examples/tixy/`, `src/examples/balloons/` — migrate (priority);
  `src/examples/{repl,guess,valid,turtle}/` — migrate or mark excluded.

## Acceptance

- Legacy globals no longer exist (calling `input_text` etc. is a `nil` call).
- `tixy` + `balloons` run on the `compy.input.*` callback API.
- Native-handler examples still work (D-9). Spec §7 edge cases hold (stop-while-active,
  show-while-active, eval-failure lock).
