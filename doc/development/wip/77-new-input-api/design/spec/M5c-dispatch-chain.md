## Scope — what this slice delivers

The complete four-tier dispatch chain of `spec.md` §2, on all three keyboard/text channels,
in the project route — plus everything the ratified model changed about M4's landed shape:

1. **The chain** (`spec.md` §2): `framework_handlers.<event>[combo]` →
   `compy.input.handlers.<event>[combo]` (per-event sub-tables, R14; normalising assignment,
   overloadable matcher — §1) → per-event generic callback (`on_key_pressed` /
   `on_text_input` / `on_key_released`, default noop + debug log) → the sink (terminal,
   internal hidden-check, no external gating wrapper). Truthy = consumed, stop. Uniform
   signatures per channel (`spec.md` §2 table), `isrepeat` threaded on keypressed.
2. **`keyreleased` unified** (ruling 4) — same chain shape, key already removed from
   `keys_pressed` when consumers run.
3. **Submit/cancel** (`spec.md` §5): tier-1 `keypressed['return']` / `['escape']` engage only
   while the widget is shown; `before_/after_submit`, `before_/after_cancel` call-order
   chains; validator gate; delivery via `on_text_entered(text)` widget output; unconditional
   deactivate step (project-route policy — spec §5 scope note); Escape genuinely dismisses;
   `hide()` fires no cancel chain. **`oneshot` deleted** — both jobs moved out of the widget;
   `push('userinput')` dissolved (spec §5 mechanism note).
4. **Widget outputs live** (`spec.md` §4): `on_text_entered`, `on_limit_reached(direction,
   scope)` (D-5 both scopes — extends `is_at_limit` to horizontal + line scope), `validator`,
   `highlighter`; config keys AND assignable fields (D-b); never chain return values (R12).
5. **Route connection per ruling 3** (`spec.md` §8): keyboard/text slots occupied only while
   `'running'`; on drop to `'project_open'` they restore to the console route — **the M4
   ruling-1 forwarding is removed**. Pointer slots untouched (Stage-1 census: `sapper` stays
   clickable). Stop = full teardown invariant (spec §8) incl. silent widget hide.
6. **Legacy natives = pure wrap** (R7, `spec.md` §8): captured at load as initial tier-3
   callback values; `native_split`/lifecycle-split wrapper deleted. **turtle + maze migrate
   in this slice** (design.md §5 sequencing constraint — never deferred to M8, else an
   interim window ships misbehaving examples). SR1 break mandate covers them.
7. **Mutable/immutable boundary** (R3, `spec.md` §7): exactly the `handlers` tables +
   `on_*`/`before_*`/`after_*` fields; everything else errors loudly on assignment.
8. **QUALITY corrective** (in-slice; per-remark disposition required in the outcome ledger —
   `fixed` or `dissolved-by-rework`, each with the remark id): C1/C15/P3 warn-on-silent-drop

   return-value propagation (now the chain contract); C9/C13 dispatch legibility; C19
   `set_love_*` table+iterator TODO; C20 `love.handlers` section comment; C23

## Risk

The widest slice of the re-cut plan (≈ twice M4's PERT) — accepted deliberately for review
coherence; mitigations: test-first red suite, ordered internal steps each independently
committed, the amended sweep mandate's mid-slice stop rules, and the hard human gate at the
boundary. Chief semantic traps: reintroducing replace-semantics anywhere (R13), letting the
sink's return leak chain meaning (R12), flattening the per-event handler tables (R14), and
"unifying" the pointer disconnect into ruling 3's keyboard/text scope (forbidden, spec §8).
