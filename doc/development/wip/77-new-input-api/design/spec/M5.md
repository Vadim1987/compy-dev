## Scope

Console/Editor controllers).

## Contract (this milestone)

- **Three-level keypressed dispatch** (in order):
  1. `framework_handlers[combo]` — Enter/Escape etc. (M6 fills these; the *tier* exists here).
  2. `compy.input.handlers[combo]` — project per-combo handlers; `fn(k, keys_pressed) → truthy|nil`;
     **return truthy to consume** (chain stops, sink does not run).
  3. `compy.input.on_key_pressed(k, keys_pressed, isrepeat)` — generic; **default value IS the
     text-editing sink**. Assigning a function replaces the default entirely — there is no
     separate tier below it.
- **`compy.input.handlers` normalisation.** Metatable-backed: `__newindex` normalises the key to
  canonical form (modifier-first, generic l/r folding) on assignment, so `'Ctrl+S'` and
  `'ctrl+s'` produce the same entry. Dispatch builds the current combo via `combo_string`
  (from M1), then matches through an **overloadable exact-match matcher**
  (`compy.input.handlers.__matcher`, default O(1) exact lookup; seam for glob/prefix).
- **Two independent channels (D-6).** `keypressed` → three-tier dispatch above; `textinput` →
  `compy.input.on_text_entered(text, keys_pressed)` whose **default value is the textinput sink**.
  Both fire independently for a character keypress — **no suppression, no classification**; no
  double-insertion because the keypressed sink ignores plain character keys.
- Bare printable-key combos (e.g. `handlers['s']`) fire on keypressed alongside `on_text_entered`
  (both channels by design).

## Files

- `src/projectInputController.lua` — add the three-level dispatch + the shared `dispatch()`.
- `src/compy_namespace.lua` (or equivalent) — expose `compy.input.handlers` (metatable);
  expose `compy.input.on_key_pressed` / `compy.input.on_text_entered` callback slots (defaulting
  to their respective sinks).

## Acceptance

- `compy.input.handlers['ctrl+s'] = fn` fires on Ctrl+S; `'Ctrl+S'` registration normalises to
  the same entry; returning truthy prevents the sink from running.
- `compy.input.on_key_pressed` fires for unregistered keys; replacing it removes the sink.
- keypressed and textinput channels both fire for a character key, with no double insertion.
- Multi-modifier combos serialise/match correctly (precedence ctrl, alt, shift, gui).
