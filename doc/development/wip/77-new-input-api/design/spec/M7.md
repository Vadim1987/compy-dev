## Contract (this milestone)

- **`compy.input.configure(config)`** — live-updates `prompt` / `highlighter` / `validator` on a
  running session (other fields accepted but no-op while active). Safe when hidden (applies on
  next `show()`).
- **`compy.input.clear()`** — clears content, cursor → position 1, no callback; no-op if hidden.
- **Cursor surface (2D `(line, col)`, 1-based, source-line coords):**
  - `compy.input.get_cursor()` → `line, col`; `nil` when hidden.
  - `compy.input.set_cursor(line, col)` → clamps to valid range; no-op when hidden. Single-line
    callers always pass `line = 1`.
- **`compy.input.set_text(text [, keep_cursor])`** — the **live-write surface** (explicit
  exception to `configure()` text-immutability) that supersedes the removed `write_to_input`. If
  `keep_cursor` truthy, preserve cursor; else move to end. No-op when hidden; triggers view update.
- **Model fix:** `UserInputModel:set_text` must honour `keep_cursor` (skip the unconditional
  `jump_end()` when set).

## Files

- `src/userInputController.lua` — add `configure()`, `clear()`, `get_cursor()`, `set_cursor()`,
  `set_text()`; fix `UserInputModel:set_text` to honour `keep_cursor`.
- `src/compy_namespace.lua` — expose `compy.input.configure` / `clear` / `get_cursor` /

## Acceptance

- `configure({prompt=…})` updates the live prompt without teardown; `clear()` resets content +
  cursor.
- `get_cursor()` returns `line,col` (or nil hidden); `set_cursor` moves + clamps;
  `set_text(t)` replaces content (cursor to end), `set_text(t, true)` preserves cursor.
- All work while active and (where defined) when hidden.
