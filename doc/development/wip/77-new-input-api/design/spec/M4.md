## Scope

Introduce `ProjectInputController` — a first-class sibling to `ConsoleController` /
`EditorController` for the project-running context — and **remove the `if user_input then`
overlay gate** in `controller.lua`. Routing becomes symmetric: the singleton is always the
sink, never a routing destination. This milestone delivers **sink delegation only**; the
three-tier dispatch arrives in M5.

## Contract (this milestone)

- **Activation.** `ProjectInputController:keypressed` / `:textinput` occupy `love.keypressed` /
  `love.textinput` when `app_state` is `'running'` / `'project_open'` (via `set_handlers()`,
  the same slot mechanism as `ConsoleController`).
- **Deactivation.** On project stop, the slot is restored to `ConsoleController:keypressed`
  (permanent baseline); project callbacks + `compy.input.handlers` reset to defaults.
- **Overlay gate removed.** `ProjectInputController:keypressed` **is** the slot occupant during
  project run — not called by special-case from `love.handlers.keypressed`. Overlay input works
  as before, via the sink; project key events are no longer silently dropped while the singleton
  is active.
- **Native-handler coexistence (D-9).** A project that defines native `love.keypressed`/
  `textinput` (captured by `save_user_handlers`) **and sets none of the `compy.*` input
  surfaces** is treated as legacy: at load, `ProjectInputController` auto-provisions
  `compy.input.on_key_pressed` as a **lifecycle-split wrapper** — singleton visible → text-editing
  sink; singleton hidden → the project's native handler. Reproduces today's gated behaviour with
  zero example changes; debug mode logs the chosen branch. (The `compy.*` surfaces this heuristic
  checks for come fully online in M5/M7; the wrapper lives with the controller here.)

## Files

- `src/projectInputController.lua` — **new**; `ProjectInputController` with `keypressed`,
  `textinput`, `keyreleased` (basic sink delegation only; M5 adds dispatch); native-coexistence
  wrapper.
- `src/controller.lua` — remove the overlay gate; wire `ProjectInputController` into
  `set_handlers()` / the `love.keypressed` slot for project-running states.

## Acceptance

- `ProjectInputController` occupies the keypressed/textinput slots during project run; restored
  to `ConsoleController` on stop.
- Overlay input still works (via sink); project key events reach the controller (not dropped).
- Native-handler examples (no `compy.*`) behave exactly as today (D-9 wrapper).
- All four app modes verified manually; full test suite passes.
