## 3. Design stress-test plan — "common sense pass" over ratified design.md

Owner's framing: design.md was validated against **stakeholder intent** (several times), never
against **post-implementation common sense** — do the approved solutions stabilize the system
(more predictable/robust) or complicate it (less understandable/fragile)? Stakeholders asked for
a *simpler and more robust input API* — the PR must not carry moving parts or vocabulary beyond
that, and whatever it carries must be justified. Some questions only became askable once the
prototype materialized. This section plans ruling them out.

### 3.1 The gate

**Reviewability gate for the PR:** a stakeholder must be able to review the PR from
`doc/input_api.md` + the PR description alone (no `wip/77` access), and the PR description must
contain a **justification table**: every net-new moving part / vocabulary item → the stakeholder
need it serves. Anything that cannot be justified in one line is a candidate for removal or
demotion to internal mechanism.

### 3.3 Process — three passes

- **Pass 1 — evidence (cheap, Sonnet/Opus agents, no rulings):** run audits A1, A2; S1
  visibility/impact sketch; S7 fixture census. Each produces a one-page evidence note under
  `../sessions/session09/` (or successor). No code changes except A1/A2 fixes if trivially
  decision-backed.
- **Pass 2 — consolidated owner ruling sheet:** one document, every S-item a row:
  keep / simplify-pre-PR / defer+ledger, each with a one-line justification that flows straight
  into the PR justification table. Rulings 1–9 (`../../reviews/owner-rulings-verified.md`) and
  C1/C2 incorporation calls get folded into the same sitting — one decision session instead of
  drips.
- **Pass 3 — execution:** apply approved simplifications (each as a focused, separately
  reviewable commit); fixture-fidelity pass; badspecref mapping application; regenerate slices;
  assemble PR whose description = intent → design → ratified deviations (D-a..D-d) →
  justification table → open questions.

**Ordering constraint:** S7 (fixture fidelity) before any Pass-2 ruling that cites green tests
as evidence; slice regeneration (item 8) last.
