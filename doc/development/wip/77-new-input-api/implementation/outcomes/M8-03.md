   ruling.** `if love.debug then project_env.astv_input = function()
   return input(LuaEditorEval) end end` (old L872-876) went with the
   rest of the machinery in the same edit. This was a debug-only dev
   tool with zero consumers (grep-clean before and after), riding the
   same `input()`/reftable plumbing as the five census globals. No
   re-decision was made here — the ruling in `M8-chunk-plan.md` was
   executed as written. Stated plainly per the ledger's mandatory
   flag.
2. **Legacy-test dispositions, both as anticipated by the commission:**
   - `describe('legacy text solicitation #legacy', ...)`
     (`input_contracts_spec.lua`, old ~L354-377) — its one test drove
     `env.user_input()`/`env.input_text('p')` to pin the C2
     warn-don't-swallow refusal behaviour. **Converted** to the AC-1
     nil-call assertion: activates a project, gets
     `F.cc:get_project_env()`, asserts each of `user_input`,
     `input_code`, `input_text`, `write_to_input`, `validated_input`,
     **and `astv_input`** is an ordinary `nil` field. Proven RED
     first (globals still present → non-nil, assertion failed with
     the actual function value printed), then GREEN after removal.
   - `'a legacy solicitation still fills the reftable on submit'`
     (old ~L1490-1501) — its subject (the reftable) no longer exists.
     **Deleted.** Checked the adjacent `'submit and cancel complete
     with no hooks set'` row first: it already asserts
     `love.state.user_input` goes `nil` on submit via
     `F.show_widget`/`F.session.press('return')` — the surviving
     half of what the deleted test covered — so deletion leaves no
     real gap. No replacement needed.
3. **The controller-side dead `result`/reftable path is now
   *provably* dead, not just presumptively so** — confirmed by
   reading (not editing) `userInputController.lua`, out of scope per
   the fence. `UserInputController:apply_config` only ever sets
   `self.result` from `cfg.result` (`userInputController.lua:223-224`);
   the removed `input()` was the **only** call site anywhere in the
   tree that ever passed `result = input_ref` into `show()`/`configure()`.
   `deliver()`'s `if type(res) == 'table' then res(text) end`
   (`userInputController.lua:364-366`) is therefore permanently
   unreachable now that its one producer is gone. **Report-don't-fix**
   per the commission — logged as tech debt below, `userInputController.lua`
   untouched.
4. **Example-doc sync is a bigger sweep than this chunk should
   carry — flagged, not silently skipped.** `internals/user_input.md`
   (required) is updated. `internals/console.md` had two small,
   self-contained legacy mentions (the `user_input` Overlay section,
   the `compy.text_input` table row) — updated, genuinely mechanical.
   But `internals/examples/{tixy,balloons,turtle,valid,repl,guess,
   index}.md` (7 files) each carry multi-paragraph prose **and code
   blocks** describing the old `r = user_input()` poll loop in
   per-example detail — a real rewrite per file, not a mechanical
   edit. Per the commission's own bounded-scope rule, these are
   **flagged as a noted follow-up**, not touched. (Also worth noting:
   `turtle.md`'s drift predates M8 entirely — turtle migrated in M5c
   and its doc was never updated then either, so this gap is a
   standing one, not newly introduced here.)
