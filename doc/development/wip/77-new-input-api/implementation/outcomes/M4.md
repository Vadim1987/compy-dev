## Design rulings made in-slice (for ratification at the gate)

1. **`project_open` occupancy vs. consumption.** `spec.md` §6 /
   `design.md` §3 say the project route occupies the keyboard
   slots in `'running'` **and** `'project_open'`; doc A §3(A) says
   non-running states route to the console. A literal
   occupancy-plus-sink reading kills the REPL after a non-blocking
   run (`sine`, `drawdebug`: run a script → `project_open` →
   typing would no-op until Ctrl+S). Reconciliation landed:
   **occupancy is the project route's for the whole run lifecycle
   (spec satisfied); consumption follows the routing model — when
   `app_state ~= 'running'` the controller forwards to the console
   defaults (doc A satisfied).** No example/UX regression; the
   real question this defers (should project handlers stay live in
   `project_open` after a non-blocking run?) has no M4-visible
   surface and is recorded for M5a commissioning.
2. **Hidden-sink no-op during `'running'`.** Previously, keys
   typed during a run with no widget and no native handler fell
   through to the *console* default and mutated the invisible
   console input line (garbage visible after stop). Now the sink
   no-ops when hidden (route exclusivity + acceptance line 3a).
   No test asserted the old behaviour; deliberate, recorded.
3. **`keyreleased` tier: descope-with-note** (human ruling,
   2026-07-02, carried — not re-asked). M4 delivers keyreleased
   delegation to the sink (shown) / native handler (hidden) only;
   no release dispatch tier is invented.
4. **Native `textinput` split stays controller-internal.** The
   D-9 auto-provision is specced for `on_key_pressed` only;
   `on_text_entered` is parked at its m5a pending. The textinput
   lifecycle split (widget shown → sink; hidden → native
   `love.textinput`) lives inside `ProjectInputController`,
   observable end state identical to today.
5. **Wrapper calling convention (transitional).** The
   auto-provisioned wrapper receives
   `(k, keys_pressed, isrepeat, scancode)` — the trailing
   `scancode` keeps the native handler on the true LÖVE
   `(k, scancode, isrepeat)` signature. Only the controller calls
   it in this slice; m5a owns the surface's public signature.
