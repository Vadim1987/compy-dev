# Lesson Reconciliation pt.2

## Software changes

### General technical provisioning

Both items below may require using a non-Compy laptop:
  - Add remote control for the teacher to run the same commands on multiple
    computers at once.
  - Make sure that projecting the teacher's screen is as easy as possible.

### Compy platform

- Prevent the navigational buttons on the bottom and notification bar at
  the top from popping up when the mouse is moved to the top or bottom of
  the screen. If this proves impossible, then disable mouse in IDE until
  the device is rooted and removal of the system navigation bar is possible.
- Child-friendly error messages: to be specified in a separate document.

### All games

- Change the notch mechanics to make it separate from the regular
  game progression. "Upping a notch" should change the whole mini-game,
  with all levels becoming more or less challenging.

### Keyboard

- Make the first three mini-games accessible for 4-6-year olds. This means:
  - Replace symbolic keyboard representation with 1:1 realistic one so
    a child who can't read can still play 100% of the game.
  - Reduce the range of keys to only numbers, letters, and basic control keys
    (space, tab, enter, backspace).
  - Possibly reduce the maximum speed.
- Exclude 4-letter sequences and reduce the maximum speed for "Hunt
  the falling objects."
- Move the rest of the keys to mini-games 4 and 5 (all punctuation).

Extra things to build for ages 7-10:

- Keyboard shortcuts (Ctrl+S, Ctrl+P, Ctrl+F, Ctrl+H, Ctrl+N, Ctrl+O, Ctrl+W,
  Ctrl+Tab, Alt+Tab, Ctrl+Alt+?, Ctrl+Shift+? etc.).
- Basic editing and navigation (arrows, Home/End, PgUp/PgDn, Ctrl-Home/End,
  Backspace/Delete, Insert/Overwrite).
- Basic text selection and manipulation (Shift+arrows, Ctrl+Shift+arrows,
  Ctrl+C/X/V, Ctrl+A, Ctrl+Z/Y).

### Mouse

  - Meet the mouse: fill up a gauge (a fixed number of cheese pieces
    collected) to win.
