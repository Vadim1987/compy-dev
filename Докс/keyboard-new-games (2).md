# Новые игры для keyboard — v3

Что изменилось против v2: рамка нотча переписана под коммит
358c3ec (нотч снова чисто учительский, без авто-климба);
порядок работ оставлен твой, противоречащий абзац из v1 убран;
Выращивание убрано из активной карты в отложенные.

## Общая рамка

Все игры стоят на действующих конвенциях, ничего нового в
инфраструктуре не требуют:

- клавиши на экране только гравированными капами, как на борде;
- текста, который нужно читать, нет нигде — игра проходима
  нечитающим ребёнком на 100%;
- победа — заполненный гейдж, дальше единый экран: кап Tab —
  следующий уровень, кап Enter — ещё раз;
- фон-пастель по уровню, выход Shift+Esc;
- нотч учительский: уровень двигает только аккорд, авто-климба
  нет. Внутри уровня подстраивается только объём задачи (длина
  волны) по гейджу — ловля добавляет, промах убавляет;
- стартовый уровень задаётся по игре через NOTCH_START; для
  младших это пол, а не нуль;
- задержки между целями — фиксированные константы, не поля
  нотч-таблицы: это сглаживание анимации, не сложность.

## В работу

### Пузырь

Нажал — надувается, отпустил — полетел, передержал — лопнул.
Судится отпускание и длительность, не нажатие: контроль
удержания, key-repeat из врага становится игрой. Уровень задаёт
окно удержания: чем выше, тем точнее надо отпустить. Ассетов не
требует — пузырь рисуется примитивами. Возрастной риск по
таймингу остаётся, снимет плейтест.

### Не нажимай

Капы падают, свой ловишь, запретный пропускаешь. Учит
импульс-контролю. Уровень задаёт скорость падения и долю
запретных. В коде дёшево, ассетов нет — всё гравировкой;
нужен твой кивок только по одному: чем помечен запретный кап
(цвет заливки, рамка, значок). Фрустрация-риск снимет плейтест.

### Прятки, скрещенные с Эхом

Цель-кап выглядывает из-за предмета и прячется. Нажать можно и
пока видно, и после того как спрятался — окно памяти. Пока
видно — обычный успех; после — «вспомнил», празднуется ярче.
Уровень: показ короче, пауза после пряток длиннее. Мягкий
мостик к памяти без полного Эха.

### Поезд

Вагоны прицепляются по клавише, поезд уезжает. По сути Канал
без таймера, для самых младших. Тип find, движок press-count.

### Астероиды, с зарядкой

Тип hunt, волновой движок. Внизу корабль, сверху падают
астероиды с капами, разбросаны по ширине. Порядок не навязан:
нажатая клавиша сбивает любой свой астероид из видимых
(лазер), чужая — холостой выстрел.

Зарядка, чтобы не выигрывалось колочением по всем клавишам:
после любого выстрела лазер перезаряжается короткий бит,
нажатия во время зарядки не стреляют; заряд виден на корабле
(свечение), без чтения. Холостой заряжается чуть дольше
меткого — спам уходит в вечную перезарядку, выгодно сначала
посмотреть. Времена зарядки — на устройстве.

Долетел до корабля — толчок, клавиша в review. Волна и гейдж
хантовские, нотч учительский по новой конвенции. Защитил
корабль норму волн — победа.

## Доработка механик

- Канал — механика расписана в v1, ждёт решения.
- Стройка — то же.
- Дуэт (Стройка на двоих) — ждёт докрутки вместе со Стройкой.

## Отложено для старших

- Эхо — память в чистом виде; частично возвращается через
  Прятки.
- Две руки.
- Ритм — отложен отдельно.
- Выращивание с засыханием — новый глагол «поддерживай»:
  несколько растений, у каждого свой кап, влага убывает,
  нажатие поливает, чью клавишу игнорируешь — то сохнет.
  Распределение внимания вместо реакции на одну цель.

## Карта пространства: глаголы и темы

Шесть глаголов в активной работе, каждый — один игровой цикл:

- нажми нужную — press, find, Поезд, (Стройка);
- нажми вовремя — hunt, Астероиды, Прятки, (Канал);
- нажми по памяти — окно памяти в Прятках, полное Эхо отложено;
- держи-отпусти — Пузырь;
- не нажимай — Не нажимай;
- нажми две — Две руки, отложено.

Седьмой глагол, поддерживай (Выращивание), отложен.

Новых глаголов клавиатура возрасту 4–6 не даёт; игры дальше
множатся темами поверх готовых глаголов.

## Часы

- Пузырь — 19 (новый цикл: судья release и длительности);
- Не нажимай — 16 (hunt-производный судья + запретные капы);
- Прятки с окном памяти — 15 (find-производный + фазы
  показа/пряток и судья окна);
- Поезд — 10 (press-count поверх, новое — рендер состава);
- Астероиды с зарядкой — 18 (зарядка: состояние, индикатор,
  баланс времён на устройстве).

Если войдут после докрутки: Канал 17, Стройка 13, Дуэт 8
поверх Стройки. Выращивание — когда вернёмся.

## Порядок работ

1. Пузырь — ассетов не нужно, стартую сразу.
2. Не нажимай — сначала утвердить визуал (метка запретного
   капа).
3. Прятки-эхо — сначала утвердить визуал, ссылки на все
   ассеты, строго CC0.
4. Поезд — сначала утвердить графику, ссылки на все ассеты,
   строго CC0.
5. Астероиды — сначала утвердить графику, ссылки на все
   ассеты, строго CC0.

твоему просмотру. Ассеты для пунктов 3–5 подберу и принесу
списком со ссылками и лицензией на каждый — до кода.
