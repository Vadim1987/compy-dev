# Новые игры для keyboard

## Общая рамка

Все игры ниже стоят на действующих конвенциях, ничего нового
в инфраструктуре не требуют:

- клавиши на экране только гравированными капами, как на борде;
- текста, который нужно читать, нет нигде — игра проходима
  нечитающим ребёнком на 100%;
- победа — заполненный гейдж, дальше единый экран: кап Tab —
  следующий уровень, кап Enter — ещё раз;
- фон-пастель по уровню, выход Shift+Esc;
- нотч по типу игры: без таймера — конвенция press/find,
  с темпом — прогрессия отдельно (климб на win-экране) и
  учительская скорость отдельно (аккорд), как в hunt.

## Три игры по заданным темам

### Стройка

Тип find, без таймера, движок press-count (gauge.lua целиком).
Сверху цель-кап. Верное нажатие — кран опускает блок, дом
растёт: фундамент, стены, окна, крыша. Дом и есть гейдж,
прогресс виден без полоски. Ошибка мягкая: блок качнулся и не
встал, цель та же; трудная клавиша потом приходит чаще — ровно
как в press. Набор клавиш растёт по прессовой лестнице
(home row, нижний, верхний, цифры); уровень выше — дом больше
и набор шире. Достроил — салют и единый экран.

### Канал

Тип hunt, волновой движок. Корабль плывёт вправо, навстречу
шлюзы, на каждом кап. Нажал до подхода — ворота открылись,
прошёл; не успел — мягко упёрся, ворота ждут ту же клавишу,
она уходит в review. Цепочка шлюзов — волна: длина растёт
через гейдж и promote. Скорость течения — учительская ось,
базовый темп и потолок длины — прогрессия. Прошёл норму
шлюзов — порт, победа.

### Астероиды

Тип hunt, волновой движок. Внизу корабль, сверху падают
астероиды с капами, разбросаны по ширине. Отличие от hunt в
судействе: порядок не навязан — нажатая клавиша сбивает любой
свой астероид из видимых (лазер), чужая — холостой выстрел.
Долетел до корабля — толчок, клавиша в review. Волна, гейдж,
promote, прогрессия и учительская скорость — хантовские.
Защитил корабль норму волн — победа.

## Идеи сверх трёх: новые циклы

### Эхо

Запомни-повтори: два-три капа подсвечиваются на борде по
очереди, гаснут, ребёнок повторяет по памяти. Первый шаг от
«вижу-нажимаю» к «помню-нажимаю», мостик к слепой печати.
Прогрессия — длина цепочки. Тема любая: светлячки, мелодия.

### Две руки

Две цели сразу: одна с левой половины борда, другая с правой,
держать вместе — мост опускается двумя опорами. Учит второй
руке: сейчас все игры проходятся одним пальцем. Удержание
инпут-слой уже умеет.

### Пузырь

Нажал — надувается, отпустил — полетел, передержал — лопнул.
Судится отпускание и длительность, не нажатие: контроль
удержания, key-repeat из врага становится игрой.

### Не нажимай

Капы падают, свой ловишь, запретный пропускаешь. Учит
импульс-контролю — отдельный навык в этом возрасте. В коде
дёшево, но есть фрустрация-риск, решает плейтест.

Приоритизация: самое ценное Эхо — память это настоящий
педагогический шаг, а цикл простой. Две руки — ценно, но UX
двух целей надо щупать на детях. Пузырь и Не нажимай —
рискованные по возрасту.

## Вариации

- Дуэт: Стройка на двоих за одной клавиатурой, цели чередуются
  левая-правая половина, дом общий. Социальная штука для
  класса, движок press-count как есть.
- Ритм: hunt-волна в такт, капы падают под бит из compy.audio.
  Цикл тот же, учительская скорость становится темпом музыки.

## Карта пространства: глаголы и темы

Для 4–6 без чтения у клавиатуры шесть глаголов, каждый — один
игровой цикл:

- нажми нужную — press, find, Стройка;
- нажми вовремя — hunt, Канал, Астероиды;
- нажми по памяти — Эхо;
- держи-отпусти — Пузырь;
- нажми две — Две руки;
- не нажимай — Не нажимай.

Новых глаголов клавиатура этому возрасту не даёт. Игры дальше
множатся темами: ребёнок различает их не механикой, а «про
мышку» и «про домик». Подходящие мотивы для возраста 4-6 лет:

- кормление: зверь просит еду, на еде кап, нажал — съел и
  доволен;
- выращивание: нажатие поливает грядку, росток растёт по
  стадиям, урожай — победа;
- поезд: вагоны прицепляются по клавише, поезд уезжает; по
  сути Канал без таймера, для самых младших;
- прятки: цель-кап выглядывает из-за предмета и прячется,
  нажать надо пока выглядывает; peekaboo, тайминг мягче
  хантовского, промах — просто спрятался опять.

Практическое следствие: утверждать стоит глаголы — их конечное
число; тема поверх готового глагола дальше стоит 6–10 часов.

## Часы и порядок

- Стройка 10–15, Канал 15–25, Астероиды 12–18. Доводка
  механик на устройстве внутри вилок, отдельной строки нет.
- Новые циклы 15–25 каждый, вариации 6–10, тема поверх
  глагола 6–10.
- Порядок: Стройка первой — движок готов целиком, новое только
  рендер; дальше Канал и Астероиды. Остальное — в бэклог по выбору.
